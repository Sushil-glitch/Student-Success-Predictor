About the Project

The Student Success Predictor is an educational data science application combining machine learning modeling, rule-based heuristics, and real benchmark analytics.

Empowering Academic Excellence

The Student Success Predictor is designed to provide actionable academic insights for educators, students, and institutions. By analyzing behavioral indicators, background parameters, and study commitments, the platform facilitates timely interventions to support student achievement.

System Architecture & Methodology

Performance Prediction (ML)

Powered by a Random Forest Regressor and verified against a closed-form Linear Regression model. Trained on the UCI Student Performance benchmark dataset (Cortez & Silva, 2008), evaluating 17 one-hot encoded features including weekly study hours, parental education, school type, education board, and test preparation course completion.

Dropout Risk (Rule-Based)

Designed as a transparent Rule-Based Heuristic Evaluation (not machine learning). It flags students as High Risk when critical thresholds are breached: attendance below 50%, previous exam marks below 40%, or low attendance (<65%) coupled with low marks (<50%) and minimal study hours (<3 hrs/wk).

Interactive Analytics & Open Datasets

The analytics dashboard displays aggregate metrics directly computed from authentic student performance data (G1 math, G2 reading, G3 composite scores, absences, and study time intervals). The platform supports dual-mode deployment: running as a Python Flask web API server, or hosted statically on GitHub Pages with deterministic client-side calculation engines.
